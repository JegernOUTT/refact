Create a focused test plan for the current task, smallest useful checks first. For each check, name the behavior it verifies and a plausible wrong implementation it would catch. Include failure and rejection cases, especially what must stay rejected when a check is relaxed; for a bug fix, start with a test that fails before the fix. Say what the plan leaves unverified.
