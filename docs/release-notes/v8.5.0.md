# v8.5.0

v8.5.0 turns the browser tool into a full Playwright-parity automation surface, adds a privacy and access layer that gates what leaves your machine, and confines shell execution behind a policy-driven sandbox.

## Highlights

- **Browser automation parity** — The `chrome` tool gains locator handlers, retrying `expect` assertions, a fake clock, network/CPU throttling, device emulation, WebSocket routing, HAR record/replay, screencast capture, and a raw CDP escape hatch. Accessibility snapshots are now the default page-changed context, so pages are read as text instead of screenshots.
- **Privacy & Access** — A new destination-first Privacy & Access page lets you decide which files may reach which destination, with zone matching, per-provider MCP tool gating, and shell output gated by runtime observation. Egress is enforced by a compiled policy and a sealed clearance gate on the LLM wire.
- **Sandboxed execution** — Shell commands run through a centralized command policy with scrubbed child environments and optional bwrap/Landlock confinement, plus a structure-aware approval gate with audit and optional LLM validation.
- **Multi-agent code review** — `review` becomes a review swarm that fans out parallel analyzers, collects deterministic evidence, and emits structured findings.
- **New providers** — Google Antigravity and xAI Grok OAuth providers, with per-provider privacy trust selection.

## Browser & Design Tools

- Locator handlers dismiss overlays before an action, and the time they spend no longer counts against the action's own timeout.
- Retrying `expect` matchers cover state, text, attributes, roles, counts, URL/title, and ARIA snapshots, with `expect_poll` for arbitrary expressions.
- Fake clock control (`clock_install`, `fast_forward`, `run_for`, `pause_at`, `set_fixed_time`) for deterministic time-dependent UI.
- Network control: route chaining with a `times` budget, `fetch_and_fulfill`, HAR record/replay, WebSocket mocking and interception, and per-request report volume control.
- `http_request` shares the page's cookie jar in both directions, so API calls and the logged-in page see one session.
- Screencast capture and `capture_frames` compose labelled filmstrips for animations and transient UI.
- Device emulation registry, network/CPU throttling, window bounds control, and a `reset` step that clears sticky session state.
- Lifecycle controls for downloads, permissions, storage, IndexedDB snapshots, and virtual authenticators for passkey testing.
- Page manipulation primitives: `set_content`, `add_script_tag`/`add_style_tag`, init scripts, and `dispatch_event`.
- Design-mode automation with guardrails: UI probing, element marking, contrast auditing, and visual diffing against explicit baselines.
- Injected JS aligned with Playwright's ARIA, shadow-DOM, and accessible-name semantics.

## Privacy & Access

- Destination-first Privacy & Access page with zone cards, pattern chips, grouped destination access, and a read-only audit matrix.
- Zone matching with path variants, alias handling that enforces the strictest zone, and zone inheritance for derived files.
- Per-provider MCP tool gating and privacy trust selection for providers.
- Shell output gated by observation, with a degraded-observation warning and a macOS fallback when runtime attribution is unavailable.
- Layered policy loading (global plus project overrides) and a canonical model-facing refusal text.
- Memory-plane vectorization is gated by policy.

## Execution & Sandboxing

- Centralized command policy and argv handling for shell execution.
- Child environments scrubbed by default; spawn confinement metadata recorded.
- Optional bwrap and Landlock confinement.
- Structure-aware shell approval gate with settings, audit trail, and optional LLM validation.

## Code Intelligence & Review

- The nine code-analysis tools return structured JSON instead of text, so results are parsed rather than scraped.
- Review swarm replaces the previous single-pass reviewer, with idle watchdogs instead of fixed timeouts and static analysis enrichment.

## GUI

- Rich rendering for the browser tool families, including a text-first page envelope on the chrome tool card.
- Settings layout, contrast, and secret masking overhauled across all sections.
- Expanded image attachments and viewer, with provider-aware image limits and a pixel guard.
- In-panel file editing with live edit playback in the files panel.
- Retry action for corrupted chat streams.

## Bug Fixes

- Browser: dead CDP transports are recovered and replay-safe rather than cached forever; transport-dead errors are distinguished from timeouts.
- Browser: HTML5 drag-and-drop, file drops, and coordinate mouse input reach page handlers.
- Browser: registries are bounded and handles RAII-guarded; WebSocket dispatch is scoped per tab.
- Claude token refresh is serialized to avoid concurrent refresh races.
- MCP status logging, config persistence, and OAuth UX improved; secrets redacted recursively on export.
- Buddy auto-applies memory ops, expires stale errors, and resolves suggestions when their controls are acted on.
- `refact` is usable in the same terminal immediately after install.

## Breaking Changes

- `strategic_planning`, `deep_research`, and `swarm_investigate` tools are removed; use the review swarm and subagents instead.
- Browser request fields are unified and unknown fields are now rejected.
- `attach_screenshot: false` is authoritative and suppresses the report screenshot.
- Virtual authenticator ids are minted server-side; callers must not supply them.
