# v8.5.1

v8.5.1 is a correctness release: it repairs Windows behaviour that had been silently wrong, restores the Antigravity and Grok provider integrations, and consolidates the agent mode set.

## Highlights

- **Windows correctness** — Several defects that only surfaced on Windows are fixed, including a `glob` tool that could never match a path, worktree files being rejected as outside the workspace, and provider config locks failing instead of waiting.
- **Providers restored** — Google Antigravity OAuth and Cloud Code requests, xAI Grok subscription auth, and quota reporting all work again; MCP no longer raises false OAuth expiry alerts.
- **Traceable subchats** — Subagent and delegate conversations are stored in per-conversation trajectory folders, so a run's child chats stay grouped with their parent.
- **Fewer, clearer agent modes** — Provider-specific and experimental mode overlays are gone, consolidating back to the base agent mode.
- **Redesigned Home and Settings** — Home becomes a single unified workstream view, and Settings moves onto one consistent visual language.

## Windows

- The `glob` tool matched nothing on Windows: candidate paths were only split on forward slashes, so a pattern like `*.rs` never reached a basename. Windows separators are now normalised before matching.
- Files inside a registered worktree were rejected with a permission error. The worktree registry verified its project hash against a canonicalised path while storing the hash of the supplied one, so any root whose spelling differed from its canonical form — 8.3 short names, or a symlinked root — discarded every record.
- Privacy zone matching could not recognise a file whose policy pattern was written in a different but equivalent spelling, and the canonical candidate was unusable because it retained the `\\?\` prefix. Guards now consider both spellings, so a rule matches more often rather than less.
- Provider config and OAuth file locks returned an error the moment another handle held the lock instead of waiting for it, so a concurrent token refresh and settings save could fail outright rather than serialise.
- Code review reported changed files using paths that did not match the rest of the engine; they are now normalised consistently.

## Providers

- Restored Google Antigravity OAuth and Cloud Code requests.
- Repaired xAI Grok subscription authentication and quota reporting.
- Suppressed false MCP OAuth expiry alerts.

## Agent & Chat

- Subchats are written into per-conversation trajectory folders, keeping a run's child chats traceable to their parent.
- Failed subchat trajectories are persisted instead of discarded, and the cache guard no longer applies to non-interactive threads.
- Removed the image shrink and omit recovery path, which invalidated the prompt cache on every retry.
- `escalate:{mode, justification}` on `shell` and `process_start` no longer forces a confirmation on every call; it prompts only when the escalation actually widens access that is being enforced.
- Unknown or dropped tools in a mode definition now produce a warning instead of failing silently.
- Dropped the provider-specific agent overlays and the `quick_agent` and `ultra_agent` modes.

## Interface

- Home is now a unified workstream view, with Live edits hidden by default and the choice remembered.
- Settings pages share one visual language, a single right edge, and optimistic project-info updates.
- The chat scrollbar ends at the composer instead of running past it.
- Background agent cards are decluttered, and the workspace file tree request no longer hangs without a timeout.
- Design-system pass across the interface: consistent box model, ambient typography, motion, control heights, and weight tokens, with light-theme and narrow-viewport corrections.

## Daemon

- The daemon relaunches correctly after a self-update.
