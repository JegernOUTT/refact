# v8.6.1

v8.6.1 is a focused fix release: stored conversations no longer accumulate privacy metadata that could never affect a privacy decision, which had grown large enough to stop some conversations from opening.

## Highlights

- **Conversations that would not open now load** — A single planner conversation had reached 217 MB on disk, of which 97.6% was file-provenance bookkeeping rather than the conversation itself; it is now 4 MB.
- **Much smaller conversation storage** — Only records that a privacy zone can act on are kept, so long agent runs no longer write hundreds of thousands of redundant entries on every turn.
- **Faster shell tool calls** — Recording observed file access no longer scales quadratically with the number of files a command touched.
- **Privacy enforcement is unchanged** — Guarded, blocked, and derived-zone records are still recorded and still block sending, including withheld shell output and read-to-write taint.

## Privacy

- File records are persisted only when they can influence an egress decision: a record is kept when it belongs to a guarded, blocked, or derived zone, or when a tool declared the path explicitly. Records that merely note an unrestricted file was touched are no longer stored, because destination checks resolve a record by its recorded zone and always allow the unrestricted one.
- Shell commands are traced at the system-call level, so a single command could previously record every file a subprocess opened, including dependency, cache, and build directories that were never shown to the model. Those entries no longer reach stored conversations.
- Summaries, handoffs, compression, and subagent seeds no longer copy forward records that cannot affect a decision, which previously let one message accumulate tens of thousands of entries.
- Withholding, denial, and zone inheritance for shell output are unaffected: they are evaluated from the full observed access set before anything is written, so guarded reads still withhold output and still taint files the command wrote.

## Tooling

- Added `tools/dev/strip_inert_privacy_records.py` to remove these records from conversations that were already saved. It preserves every guarded, blocked, derived-zone, and declared record, rewrites files atomically, and supports a dry run.
