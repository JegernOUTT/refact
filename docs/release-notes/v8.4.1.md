# v8.4.1

v8.4.1 reworks the workspace into a proper cockpit — files, git, tasks, and terminal now live in a persistent dock and resizable drawer, all scoped to the chat you are working in and refreshed live as the agent edits.

## Highlights

- **Workspace cockpit** — Files move into a persistent dock, the terminal into a resizable bottom drawer, and git changes/commit into the dock with diffs and log in the main area. Adds a tasks dock section, resizable splitter, and motion transitions.
- **Everything is chat-scoped** — Terminal sessions, file surfaces, git state, and worktrees now follow the chat you have focused, with the terminal's working directory set to that chat's worktree.
- **Live edit refresh** — Open files, the file tree, and git status refresh automatically as the agent edits, with auto-split so you see the edited file without hunting for it.
- **Smarter tool arguments** — The engine now coerces sloppy LLM tool arguments to their declared schema types instead of failing the call.
- **Configurable daemon port** — The daemon control port can now be set explicitly (#19).

## Workspace

- Files relocated into a persistent dock with a resizable splitter.
- Terminal moved into a resizable bottom drawer; per-chat workbench sits above the composer.
- Git changes and commit moved into the dock; diff and log render in the main area.
- Tasks dock section and git status added to the dock switcher.
- Global workspace panels toggle available for all hosts.
- Motion transitions for dock, drawer, and tabs; dock/drawer chrome polished.
- Chat context preserved for file surfaces; context surfaces close when their chat closes.
- Live edits toggle exposed in the toolbar.

## Files & Git Panels

- File type icons and a gitignore-aware tree.
- Expanded directories refresh on live changes.
- Commit message generation button in the git panel.
- Breadcrumbs scoped to the workspace root; ancestors above the root no longer expand.
- Enclosing git repo discovered for subdirectory workspaces.

## Engine

- Sloppy LLM tool arguments are coerced to their declared schema types.
- `code_review` and `subagent` tool results are no longer truncated under the shared budget.
- Mode and subagent customizations no longer revert to defaults (#24).
- Git risk analysis resolves the enclosing repository correctly.

## Daemon & Dashboard

- Daemon control port is configurable (#19).
- Home fan-out no longer re-runs on every poll and refreshes on project recency changes.
- Project health loads instead of aborting.
- Doctor and usage panels polished; missing project roots grouped.
- Setup wizard auto-completes for established installs.
- Request bodies buffered in the GUI fetch shim.

## Bug Fixes

- Terminal reattachment is authoritative; PTY size syncs on attach and themes with dark tokens.
- Expanded workbench body gets real height.
- Exec enforces chat ownership; terminal spawn/list/access scoped by `chat_id`.
- Raw PTY bytes stream correctly for TTY processes over SSE.
- Default shell resolved on the backend instead of the GUI.
- Worktree checkout and registered root identity validated on reads.
- Non-content diff lines are no longer prefixed with an origin character.
- External symlinks are no longer dereferenced during git reads.
- Missing configured git roots are skipped instead of failing the request.
- Workspace chrome and keyboard shortcuts gated by host capabilities; shortcuts stay active on non-typing inputs.
- Narrow dock stays below the toolbar; bottom dock clearance unified in chat.
- Cancelled tab closes finalize correctly; dock counters and navigation corrected.
- IntelliJ loads chat from the daemon project origin.
