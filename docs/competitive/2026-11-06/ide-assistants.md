## Cline

* **Aug 6 — [v4.1.6](https://github.com/cline/cline/releases/tag/v4.1.6), stable:** refreshed the Cline provider catalog, including Muse Spark 1.2 Contributor; corrected model attribution in error telemetry.
* **Aug 9 — [v4.1.7](https://github.com/cline/cline/releases/tag/v4.1.7), stable:** pre-registered OAuth clients for remote MCP servers; durable session context across aborts and hub restarts; scheduled-run reports carry execution context.
* **Aug 11 — [v4.1.8](https://github.com/cline/cline/releases/tag/v4.1.8), stable:** arbitrary Vertex model IDs and full regional catalog; made auto-approve the source of truth for unattended runs, removing the nonfunctional Yolo toggle and migrating existing unattended configurations to approve every action. Separately, the [Aug 11 model announcement](https://cline.bot/blog/nvidia-nemotron-3-5-lightning-available-in-cline) made Nemotron 3.5 Lightning available free through Cline usage billing; an unversioned provider announcement, not evidence of a simultaneous release of another product.
* **Aug 13–14 — [v4.1.9](https://github.com/cline/cline/releases/tag/v4.1.9) and [v4.1.10](https://github.com/cline/cline/releases/tag/v4.1.10), stable:** v4.1.9 fixes the Claude Code provider's agentic tool usage and loads its local permission settings, for SDK-bundle windows. On Aug 14 v4.1.10 added optional web search for supporting models with persisted results and added Crusoe to the provider catalog.
* **Aug 21–23 — [v4.1.12](https://github.com/cline/cline/releases/tag/v4.1.12), [v4.1.13](https://github.com/cline/cline/releases/tag/v4.1.13), [v4.1.15](https://github.com/cline/cline/releases/tag/v4.1.15), stable:** enterprise MCP marketplace disablement and server allowlists are enforced; two releases fix custom OpenAI-compatible models losing tool calling due to capability inference; the MCP auto-approval switch now actually covers all MCP tools. The [Sept 2 migration account](https://cline.bot/blog/how-we-migrated-11-million-users-to-clines-biggest-harness-upgrade) reports the SDK-based extension rollout reached 100% on **Aug 23**, as windows update and reload, after an earlier rollback. The new shared runtime revises prompts, tool discovery, context and error handling; some less-used features were deprecated. This rollout date is retrospective, not the article date.
* **Sept 2 — [v4.1.17](https://github.com/cline/cline/releases/tag/v4.1.17), stable:** fixed Hub memory growth caused by repeatedly broadcasting complete transcripts during long sessions; exposed ClinePass information and corrected a malformed-request chat crash.
* **Sept 14 — [Cline Desktop announcement](https://cline.bot/blog/cline-desktop-an-open-source-app-for-open-weight-models), early version, Windows beta:** parallel sessions, recurring scheduled agents, conversation import from supported agents, web search and voice; marketplace for plugins, MCP servers and skills. It supports provider choice, local models and separate Plan/Act models; desktop capabilities should not be assumed to ship on that date in the extension.
* **Sept 17–24 — [v4.1.19](https://github.com/cline/cline/releases/tag/v4.1.19), [v4.1.20](https://github.com/cline/cline/releases/tag/v4.1.20), [v4.1.21](https://github.com/cline/cline/releases/tag/v4.1.21), stable:** corrected long-task compaction triggering and warned when a selected model cannot see attached images; same-step subagents can run tool calls concurrently while the parent waits for all results; provider catalog and defaults changed. v4.1.21 also raised js-yaml's minimum version for a parser security fix affecting rules and skill frontmatter.
* **Sept 30–Oct 26 — [v4.1.22](https://github.com/cline/cline/releases/tag/v4.1.22), [v4.1.23](https://github.com/cline/cline/releases/tag/v4.1.23), [v4.1.24](https://github.com/cline/cline/releases/tag/v4.1.24), [v4.1.25](https://github.com/cline/cline/releases/tag/v4.1.25), [v4.1.26](https://github.com/cline/cline/releases/tag/v4.1.26), stable:** provider and default-model changes, Anthropic refusal fallback and clearer filter errors; compatible reasoning levels are selected for restricted models. v4.1.26 adds separate cloud model configuration and sandbox start/resume progress, and hides inapplicable local approval and Plan/Act controls in cloud sessions.

## Kilo Code

* **Aug 10–11 — [JetBrains v7.0.15](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.0.15) and [v7.4.21](https://github.com/Kilo-Org/kilocode/releases/tag/v7.4.21), stable:** JetBrains can include active/open files, selections and available shell context in prompts, with a setting to disable automatic context. The VS Code release improved Agent Manager terminal keyboard focus and provider-aware model search.
* **Aug 18–27 — [JetBrains v7.1.0-rc.2](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.0-rc.2) and [rc.3](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.0-rc.3), prerelease; [v7.1.0](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.0), stable Aug 27:** worktree-based Agent Manager is explicitly beta, with sessions, status and terminal integration; tool cards display approval reasons and diffs. The RC dates are not the stable date.
* **Aug 20–28 — [v7.4.23](https://github.com/Kilo-Org/kilocode/releases/tag/v7.4.23), [v7.5.0](https://github.com/Kilo-Org/kilocode/releases/tag/v7.5.0), [v7.5.4](https://github.com/Kilo-Org/kilocode/releases/tag/v7.5.4), and [JetBrains v7.1.1](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.1), stable:** review threads can be sent to an agent; orchestrators can answer managed sessions' pending questions; inline Agent Manager diffs improve review. v7.5.4 fixes Windows startup failure; JetBrains v7.1.1 preserves transcript and workspace context on retry and fixes empty subagent results.
* **Sept 8–23 — [v7.5.16](https://github.com/Kilo-Org/kilocode/releases/tag/v7.5.16), [v7.7.3](https://github.com/Kilo-Org/kilocode/releases/tag/v7.7.3), [v7.7.4](https://github.com/Kilo-Org/kilocode/releases/tag/v7.7.4), [JetBrains v7.1.7](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.7), stable:** send failed CI checks to an agent, repair or clean up stale worktrees, and show ChatGPT Codex quota. An experimental setting calls MCP tools through confined JavaScript and discovers them on demand. JetBrains adds marketplace agents, MCP servers and skills, plus Swarm board collaboration. The [Sept 17 RC](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.7-rc.2) preceded the stable JetBrains release.
* **Sept 29 — [Sign in with ChatGPT announcement](https://blog.kilo.ai/p/sign-in-with-chatgpt), unversioned:** ChatGPT login and subscription-backed inference became available across VS Code, JetBrains, CLI, cloud agents, code review and mobile. It draws on included ChatGPT Work/Codex usage up to plan limits or a lower configured limit, instead of per-token API billing; Gateway models remain separate options.
* **Oct 6 — [Kilo Desktop announcement](https://blog.kilo.ai/p/desktop), unversioned:** named multifolder workspaces; Code, Plan, Ask and Debug agents, with approved plans split into parallel subagent work; custom agents, notebook editing, conda environments, terminals/diffs, local model server and 500+ model choices. Marketplace skills/MCP/agents and enterprise policy controls were described for Desktop, not automatically for every IDE surface.
* **Oct 8–16 — [JetBrains v7.1.9](https://github.com/Kilo-Org/kilocode/releases/tag/jetbrains/v7.1.9), [v7.8.12](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.12), stable:** JetBrains MCP OAuth sign-in and recovery; gateway endpoint routing updated. On Oct 16 Kilo [announced](https://blog.kilo.ai/p/cursor-exodus) free Kilo Enterprise for qualifying Cursor customers for the rest of their contract, up to one year, subject to claim and verification; the offer is not a general permanent price change.

* **Oct 26 — [v7.8.18](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.18), stable:** the VS Code patch updates DOMPurify to 3.4.17 for Dependabot-flagged sanitization issues and Vite to 7.3.7 for CVE-2026-112944; it also fixes copying selected chat text. The CLI patch updates the MCP SDK for security issues and changes cross-origin redirect behavior.
* **Nov 5 — [v7.8.27](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.27), stable:** release notes say “No notable changes.”
