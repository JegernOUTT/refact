Products: Hermes Agent (NousResearch/hermes-agent), OpenClaw (openclaw/openclaw), Ouroboros (**Q00/ouroboros**, not the razzant project) and Repowise (repowise-dev/repowise).

**Method and evidence rules**
- Main evidence: first-party GitHub Releases. I read them from the shared inventory `docs/competitive/2026-11-06/github-releases.json` (acquired 2026-11-06T05:20Z) and checked them against my own unauthenticated API fetch. The in-window tag sets matched exactly for all four repos. OpenClaw's in-window stable releases point to per-version first-party changelogs (`CHANGELOG/<ver>.md`, mirrored at docs.openclaw.ai/releases/<ver>). I read 10 of those directly.
- Dates are GitHub `published_at` (UTC). Where the release body gives a different "Release Date", both dates are shown.
- READMEs and product sites only describe current capability. They are never used as evidence that something launched in the window. Every performance, savings or cost figure below is a **vendor claim**; none was verified.
- Identity: `Q00/ouroboros` describes itself as "Agent OS … Interview-gated, staged evaluation, budgeted evolution loop. MCP server, 14 runtimes." It is a spec-first loop/orchestration layer over Claude Code, Codex and other hosts. `razzant/ouroboros` was not examined.

- **Memory/skills/learning:** Hermes (curator lock, auto_load, catalog memory providers), OpenClaw (Skill Workshop 1→2.0, Incognito exclusion, Knowledge Scribes beta), Repowise (episodes, decisions as agent memory). Ouroboros is the exception: its focus is evidence-gated evaluation, not memory.
- **Subagents/orchestration:** live steer/stop in Hermes (v0.21.0, v0.22.0) and OpenClaw (Subagents panel); pluggable delegation in Hermes v0.23.0; Ouroboros host subagent dispatch over MCP and multi-runtime (dsh, OMP, Antigravity).
- **Gateway/channels/scheduler:** Hermes one-gateway-per-machine and cron memory; OpenClaw X channel, MCP-event automations, ChatGPT/Claude remote control.
- **Permissions/sandbox:** Hermes bwrap plugin and spend limits; OpenClaw secret-egress binding and workspaceOnly; Ouroboros execution sandbox (Linux, Windows AppContainer) and two `.env` injection advisories; Repowise principal-scoped auth.
- **Code intelligence:** only Repowise ships graph/health/wiki/risk features in this set.
